## Reading and maintenance rules

Read the source in chapter order. Before recording each new fact, consult the relevant existing catalog entry. If no entry exists, search the catalog before adding one. Update affected entries and complete the chapter review before advancing to the next chapter.

Use English throughout. Base each English name on its Russian nominative form; grammatical case forms do not establish separate people or places. Tie every number and duration to the exact event it modifies. Mark an inferred motive or cause as interpretation. Use stable transliterated names and record aliases. Cite part and chapter IDs and link to the source map. Distinguish witnessed events, a character's report, public claims, inference, and unresolved questions. Preserve the earlier state when a later chapter changes a relationship, office, identity, or explanation.

A later revelation is not automatically a contradiction. A lie, mistaken belief, unexplained gap, conflicting number, and confirmed continuity error must have separate labels. Cite both sides of each conflict. Record a later resolution without erasing the original evidence.

No Hindsight is used. Source text remains unchanged. Operational progress belongs in the work ledger and activity notes; narrative uncertainty belongs in the continuity register.
